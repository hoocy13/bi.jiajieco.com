## 诊断响应头

后端响应提供：

- `X-Request-ID`
- `X-Response-Time-Ms`
- `X-DB-Query-Count`
- `X-DB-Time-Ms`
- `X-DB-Slow-Query-Count`
- `X-ODS-Query-Count`
- `X-ODS-Time-Ms`
- `X-ADS-Query-Count`
- `X-ADS-Time-Ms`
- `Server-Timing`

慢查询日志只记录请求 ID、接口路径、数据库类型、耗时和 SQL 指纹，不记录 SQL 参数、账号、Token 或业务明细。

## 首期验收目标

- 常用接口预热后 P95 不超过 1 秒。
- 核心 ADS 冷查询不超过 3 秒。
- 热访问 P95 不超过 500 ms。
- 相同参数并发只触发一次 ADS 查询。
- 优化前后业务指标核对一致。
