# RAG MVP 知识库

本目录保存经过业务负责人审核、可以作为 Jiajieco BI 智能分析助手证据的知识。

## 目录

```text
metrics/          指标定义
tables/           数据表和字段语义
pages/            BI 页面说明
sql-examples/     已审核的只读 SQL 示例
playbooks/        经营分析和排查流程
faq/              标准问答
evaluation/       黄金问题与期望结果
```

## 发布流程

```text
创建或修改草稿
  → 业务负责人审核口径
  → 提交 Git
  → 执行入库
  → 运行相关黄金问题
  → 验证通过后切换 active 版本
```

V1 只处理 UTF-8 Markdown 和 YAML。订单、库存明细和当前销售额等动态事实不写入
知识库，由现有 BI 指标接口或只读 Text-to-SQL 查询。

## 编写规则

1. 每条知识必须有稳定 `id`、负责人、状态和更新时间。
2. `status: draft` 的内容不得发布到生产索引。
3. 指标必须写清定义、公式、数据源、默认筛选和限制。
4. 数据表必须写清业务用途、日期字段、业务键和禁止用法。
5. 不记录账号、密码、API Key、Token、客户联系方式和其他敏感信息。
6. 修改业务口径时同步增加或更新 `evaluation/` 中的验收问题。
