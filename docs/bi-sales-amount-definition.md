# BI 销售金额口径

## 结论

- 销售总览、订单明细、订单渠道与城市分析使用“订单实付金额”。
- 商品、品牌、品类、明细渠道、客户与库存周转分析使用“明细分摊销售额”。
- 两种金额是不同业务指标，不要求直接相等，不跨口径对账。
- 两种金额的差额不代表平台抽成。平台费用和结算净额只能基于平台结算数据计算。

## 指标定义

| 指标 | 计算 | 用途 |
|---|---|---|
| 订单实付金额 | 有效订单头 `实付金额` 合计 | 整体销售规模、订单付款、订单级渠道与城市分析 |
| 明细分摊销售额 | 销售商品明细 `分摊后金额` 合计 | 商品、品牌、品类、明细渠道、客户和周转分析 |
| 商品毛利 | 明细分摊销售额 - 商品成本 | 未扣除平台费用的商品经营毛利 |
| 平台结算净额 | 平台结算收入 - 佣金、服务费等 | 待接入平台结算数据后使用，当前 BI 不推算 |

## 对账规则

- 销售数量可在相同日期和有效订单范围内进行订单头与明细对账。
- 品牌、商品、正装/小样、线上/线下之间，只对账明细分摊销售额。
- 订单实付金额只在订单头口径内对账。
- 相同页面同时展示两种口径时，必须在标题或图例中标明口径。

## 数据流边界

本规范只约束 BI 展示、指标命名和问数语义，不修改 ODS、DWD、ADS 的现有数据流，不重算历史数据。
