# 年会赛事首版（2026-11-10）

后台 `/annual-match`，沿用 system.users.manage 管理权限。公开观赛 `/events/:token`，需管理员在“公开展示”中开启；默认关闭、默认隐藏姓名。匿名只能观看，主持人抽签必须登录并再次校验权限。

每场逐次抽取10人，按位置分成两队，9场组成18队。空位置视为随机补位；预先检查90人阵容可行性，避免位置偏好影响随机入选机会。未公布候选名单不返回公开接口。打开抽签先进入待抽取舞台，点击开始后动画揭晓。

赛制18进9、4场争夺四强加1队待定；待定队由管理员指定一支暂晋级队挑战，BO5胜者接替其四强席位；前两轮BO3，资格赛、半决赛和决赛BO5，支持比分及逐局Ban。

管理页支持改队名、放弃并完整归档抽选、恢复最近5次记录。有下游比分时保护晋级结果；并发操作使用revision校验。

生产数据库由 ANNUAL_MATCH_DB_PATH=/app/data/annual_match.db 指向现有 backend_data 持久卷；不涉及ODS、ADS或账号库迁移。不上传本地测试赛事数据库、比分或令牌。首次访问初始化91人名单。

本地验证：34项年会单元/API测试、Python编译、独立发布工作区前端构建；浏览器已核对公开页、抽签舞台、改名和晋级占位文字。生产发布采用现有 Deploy BI workflow，保留生产.env与数据卷。
